# Unreal Engine version reference

**Target:** Unreal Engine 5.8. Epic released it in June 2026. Some features
in the release are Beta or Experimental; check their status in the versioned
documentation before adopting them for production.

This repository does not bundle an Unreal project or verify all engine
features. Pin the exact engine version in each game project.

Official sources:

- [Unreal Engine 5.8 announcement](https://www.unrealengine.com/news/unreal-engine-5-8-is-now-available)
- [Unreal Engine documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine)
