# Godot version reference

**Target:** Godot 4.7.2 stable. Godot 4.8 is a development release as of
September 2026. Pin the exact editor version in each game project and test
engine upgrades before changing an existing project.

This repository's Godot notes are starting points, not a substitute for the
versioned engine documentation.

Official sources:

- [Godot release archive](https://godotengine.org/download/archive/)
- [Godot 4.7 documentation](https://docs.godotengine.org/en/4.7/)
