# Unity version reference

**Target:** Unity 6.3 LTS (6000.3). Unity lists support through December 2027.
For new projects in active development, Unity also offers supported Update
releases; choose a specific editor version and record it in the game project.

This repository does not bundle a Unity project or prove compatibility with
every Unity package. Check the exact editor and package versions before using
an example in production.

Official sources:

- [Unity 6 release support](https://unity.com/releases/unity-6/support)
- [Unity 6.3 LTS changes](https://docs.unity.com/en-us/engine/6000.3/manual/whats-new/unity63)
