# Agent Instructions

Game Dev Studio is a reusable documentation and workflow toolkit for AI coding agents working on games.

- Read the relevant `SKILL.md`, agent definition, or engine reference before editing it.
- Keep README counts synchronized with the actual files; do not claim planned features.
- Treat install, build, and file-writing commands as explicit user actions.
- Run `bash scripts/validate.sh` after structural changes.
- Keep engine versions in `engine-refs/*/VERSION.md` and the README aligned.
- Preserve original project attribution and license notices.
